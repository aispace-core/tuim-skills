# 创业点子生成器

基于趋势、痛点和市场空白，生成可落地的创业想法。与「创业验证」配套使用，形成从灵感迸发到想法验证的完整工作流。

**Hexa 原则：** "好点子不是想出来的，是从真实的裂缝里挖出来的。"

**辩证原则：** "任何机会都藏着危机，任何危机都藏着机会。看得见正面的叫乐观，看得见背面的叫智慧。"

**厚黑原则：** "商业的本质是博弈。你在找痛点，别人也在找。谁先看懂人性，谁就赢。"

## 触发场景

- 用户说"我想创业但不知道做什么"
- 用户问"有什么创业方向"
- 用户想探索某个领域的机会
- 用户在寻找下一个创业灵感

## 核心框架

**点子生成 = 趋势扫描 + 痛点挖掘 + 市场空白识别 + 可行性过滤**

### 1. 趋势扫描

| 趋势类型 | 探测信号 | 问题化切入点 |
|----------|----------|---------------|
| 技术趋势 | AI、成本下降、开源 | 这替代了什么传统方案？ |
| 监管趋势 | 新规、禁令、补贴 | 合规压力创造什么需求？ |
| 人口趋势 | 老龄化、单身、小镇 | 人口结构变化催生什么服务？ |
| 行为趋势 | 远程、即时、订阅 | 消费习惯迁移留下什么空白？ |
| 竞争趋势 | 大厂撤退、竞品老化 | 格局松动露出什么机会？ |

### 2. 痛点分层

| 层级 | 特征 | 点子类型 |
|------|------|----------|
| 高频重度 | 每天痛、有预算、主动找方案 | 工具类产品 |
| 低频刚需 | 偶尔但必须、替代成本高 | 服务类产品 |
| 情绪价值 | 不痛但不爽、愿意为体验付费 | 消费品类 |
| 效率焦虑 | 知道有问题但没时间解决 | 效率工具类 |

### 3. 市场空白识别

| 空白类型 | 识别方式 | 切入难度 |
|----------|----------|----------|
| 替代空白 | 现有方案贵/差/难 | 中等 |
| 增强空白 | 现有方案缺某个功能 | 较低 |
| 迁移空白 | 用户想换但换不了 | 中等 |
| 创造空白 | 问题存在但未被定义 | 较高 |

### 4. 可行性过滤器（辩证版）

| 过滤维度 | 检查项 | 通过条件 | 反面陷阱 |
|----------|--------|----------|----------|
| **可做成** | 技术是否成熟？资源是否够？ | 有 MVP 路径 | 技术门槛低 → 大厂也能做 |
| **有人要** | 用户是否真的愿意付费？ | 有真实需求信号 | 需求可能是自己意淫的 |
| **有人买** | 谁付钱、决策链是否清晰？ | ICP 明确 | 付钱的人和用的人不是同一个 |
| **来得及** | 窗口是否还在？大厂会跟进吗？ | 有 18 个月先发优势 | 先发优势可能是靶子 |

### 辩证自问清单

每个方向都要过一遍「暗黑三问」：

1. **谁会恨我？**
   - 这个点子动了谁的奶酪？
   - 谁最有动力把我打死？
   - 监管会盯上我吗？

2. **谁在笑？**
   - 投资人笑 = 他们要接盘
   - 用户笑 = 他们要占便宜
   - 竞品笑 = 我踩了坑

3. **我能撑多久？**
   - 没有融资我能活多久？
   - 如果大厂抄袭，我的护城河在哪？
   - 如果用户不来，我会怎么办？

## 点子生成流程（辩证版）

### 阶段 1：信息收集（加厚黑视角）

引导用户回答：

> **告诉我你的背景和偏好：**
>
> 1. 你有什么行业经验或资源？
> 2. 你偏好什么类型的创业？（技术驱动/服务驱动/产品驱动）
> 3. 你的启动资源是什么？（资金/技术/行业关系）
> 4. 你有什么不能做的？（监管/能力/资源限制）
> 5. 你能得罪谁？（谁的利益会受损？）
> 6. 你背后有没有人在推？（资源/靠山/关系）

### 阶段 2：趋势+痛点叠加（加辩证视角）

根据用户背景，选择 2-3 个相关趋势，将其与 1-2 个痛点层级叠加，生成 3-5 个候选方向。

**每个方向必须标注：**
- **表面机会**：看起来是什么
- **底层逻辑**：为什么会存在这个空缺
- **可能的陷阱**：大厂为什么不做/用户为什么不来

### 阶段 3：快速过滤（辩证版）

对每个候选方向过一遍「可行性过滤器」+「暗黑三问」，给出每个方向的：
- **机会描述**
- **关键假设**
- **验证路径**
- **风险点**
- **谁会阻挡**（新增）

### 阶段 4：精选输出（辩证版）

给出 1-3 个最值得深挖的方向，每个包含：

```markdown
## 方向 X：[方向名称]

**一句话机会：** [对谁、在什么场景、解决什么问题]

**为什么是现在：**
- [趋势 1]
- [趋势 2]

**暗面自检：**
- 谁会恨我：[利益受损方]
- 什么会杀我：[最大威胁]
- 我能活多久：[生存时间窗口]

**最小验证路径：**
1. [第一步行动]
2. [第二步行动]

**最大风险：**
[如果这个假设错了，点子就废了]

**建议下一步：**
[用创业验证评估此方向]
```

## 与创业验证的联动

| 当前阶段 | 下一步工具 |
|----------|------------|
| 有方向但不确定 | → 创业验证 |
| 有方向需要 ICP | → startup-icp-definer |
| 需要估算市场规模 | → market-sizer |
| 需要找种子用户 | → leads-researcher |
