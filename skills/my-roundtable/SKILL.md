# My Roundtable

把任何话题变成一场有张力的圆桌讨论节目。

## 核心原则

**冲突设计比观点罗列更重要**
- 嘉宾之间必须有真实立场冲突，而非程度差异
- 价值观层面存在根本分歧，拒绝"最后都同意"
- 每轮讨论必须推进议题深度，不能原地重复

**角色必须可信且差异化**
- 姓名+身份+核心立场+性格特质+冲突点 = 完整人设
- 发言风格必须因人而异，不能千人一面
- 允许合理虚构背景、数据、案例，但必须可信

## 工作流

1. **分析话题** → 识别核心争议点，确定3-4个冲突维度
2. **设计阵容** → 1位中立主持人 + 3-4位立场鲜明的嘉宾
3. **输出议程** → 5轮结构（破冰→争议引入→矛盾激化→深挖本质→展望结论）
4. **逐轮讨论** → 每轮完整呈现所有嘉宾发言，主持人穿针引线
5. **总结提炼** → 共识/分歧/开放问题

## 输出结构

### 角色阵容（每条必须包含）
```
【主持人】
姓名 · 职位
风格标签：[中立追问型/犀利引导型/温和梳理型]

【嘉宾阵容】
① 姓名 · 身份
   立场：[一句话核心观点]
   性格：[特质描述，影响表达风格]
   冲突点：[与其他嘉宾的根本分歧]

② 姓名 · 身份
   ...

（3-4位，至少一对嘉宾在价值观层面根本对立）
```

### 议程大纲
```
第一轮：[破冰定调] —— 各自亮出基础立场
第二轮：[引入争议] —— 引入对立案例或数据
第三轮：[矛盾激化] —— 直接点名反驳，立场碰撞
第四轮：[深挖本质] —— 追问核心分歧的根源
第五轮：[展望结论] —— 未来展望与开放问题
```

### 逐轮讨论格式
```
【第X轮】[本轮主题]

🎙️ 主持人：
[提问。点名矛盾，直指要害，不回避敏感问题]

👤 嘉宾A（身份简称）：
[回答。150-300字，符合立场性格，可反驳、可引用数据案例]

👤 嘉宾B（身份简称）：
[回答。直接回应A，语气符合性格]

👤 嘉宾C（身份简称）：
[回答。第三视角或支持某方附加新条件]

🎙️ 主持人 过渡语：
[点出张力，简短有力，引出下一轮]
```

### 主持人总结
```
━━━━━━━━━━━━━━━━━━━━━━━━
【主持人总结】

🎙️ 主持人姓名：

[核心争议梳理：各方立场与根本分歧]

[共识与分歧：达成了什么，悬而未决什么]

[开放问题：留给听众的思考]

感谢各位。这场争论或许才刚刚开始。
━━━━━━━━━━━━━━━━━━━━━━━━
```

## 质量标准

| 维度 | 要求 |
|------|------|
| 冲突感 | 每两轮至少一次直接点名反驳 |
| 观点演进 | 至少一位嘉宾立场在讨论中发生变化 |
| 发言长度 | 每位嘉宾每轮150-300字实质内容 |
| 性格一致 | 激进者打断引申，学术派引数据，情绪化者用例说话 |
| 节奏控制 | 分批输出，每轮后标注"▶ 继续第X轮" |

## 输出节奏

- **默认分批输出**：角色阵容+第1轮 → 用户确认 → 第2轮 → ... → 总结
- **一次性输出**：用户明确要求时，连续输出所有内容
