# 圆桌讨论执行指南

本文件提供 my-roundtable 的详细执行规范，SKILL.md 是主入口。

---

## Step 1：分析话题，设计角色阵容

### 内部思考清单
1. 话题的核心争议点是什么？
2. 哪些维度/立场之间存在真实冲突？（技术vs伦理、资本vs劳工、传统vs创新...）
3. 什么样的人物背景天然带来这些立场？

### 主持人设计
| 属性 | 要求 |
|------|------|
| 职业 | 资深媒体人/学者/行业观察者（贴合话题） |
| 性格 | 理性中立、善于追问、偶尔犀利 |
| 禁忌 | 不表达强烈个人立场 |

### 嘉宾设计（3-4位）

**每条必须包含：**
- 姓名（真实感的中文或英文名）
- 身份（具体职位+机构）
- 核心立场（一句话）
- 性格特质（影响表达风格：激进/学术/情绪化/冷静...）
- 与其他嘉宾的潜在冲突点

**冲突设计原则：**
- 至少一对嘉宾在价值观层面根本对立，不只是程度差异
- 至少一位嘉宾的立场会随讨论推进而动摇或激化
- 避免"最后都同意"的结局

## Step 2：输出格式规范

### 初始输出
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎙️ 圆桌会议：[Topic]
━━━━━━━━━━━━━━━━━━━━━━━━━━━

【主持人】
姓名 · 职位
风格：[中立追问型/犀利引导型/温和梳理型]

【嘉宾阵容】
① 姓名 · 身份
   立场：[核心观点]
   性格：[特质]
   冲突点：[与其他嘉宾的根本分歧]

② 姓名 · 身份
...

【议程】
第一轮：[破冰定调] —— 各自亮出基础立场
第二轮：[引入争议] —— 引入对立案例或数据
第三轮：[矛盾激化] —— 直接点名反驳
第四轮：[深挖本质] —— 追问分歧根源
第五轮：[展望结论] —— 未来展望与开放问题

━━━━━━━━━━━━━━━━━━━━━━━━━━━
[主持人开场白，1-2段，设置讨论氛围]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 逐轮格式
```
【第X轮】[本轮主题]

🎙️ 主持人：
[提问。点名矛盾，直指要害，不回避敏感问题]

━━━

👤 嘉宾A（身份简称）：
[回答。150-300字，符合立场性格，可反驳、引用数据]

👤 嘉宾B（身份简称）：
[回答。直接回应A，语气符合性格]

👤 嘉宾C（身份简称）：
[回答。第三视角或支持某方附加新条件]

（如有第四位）
👤 嘉宾D（身份简称）：
[回答]

━━━

🎙️ 主持人 过渡语：
[点出张力，引出下一轮]
```

### 总结格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
【主持人总结】
━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎙️ 主持人姓名：

[核心争议梳理：各方立场与根本分歧]

[共识与分歧：达成了什么，悬而未决什么]

[开放问题：留给听众的思考]

感谢各位。这场争论或许才刚刚开始。
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## Step 3：执行要点

### 回答质量要求
| 维度 | 标准 |
|------|------|
| 长度 | 每位嘉宾每轮150-300字 |
| 真实感 | 引用数据、亲身经历、行业案例（可合理虚构） |
| 冲突感 | 每两轮至少一次直接点名反驳或情绪升温 |
| 性格一致 | 激进者打断引申，学术派引数据，情绪化者用例说话 |
| 观点演进 | 某些嘉宾立场在讨论中细微变化 |

### 禁忌
- 嘉宾观点趋同
- 回答空洞说教
- 过度礼貌
- 无意义争吵

---

## Step 4：输出节奏

**默认分批输出：**
1. 角色阵容 + 议程 + 第1轮
2. 用户确认后输出第2轮
3. ...依此类推
4. 最后一轮后输出总结

**一次性输出：** 用户明确要求时，连续输出所有轮次。

---

## 风格基调

- 语言：中文为主
- 氛围：真实的电视/播客圆桌节目感
- 关键词：有张力、有温度、直接交锋、观点转折
