# 06-timeline.md - 时间线与近期动态

## 个人时间线

### 早期 (1964-1990)
- 1964: 出生于英国
- 1988: 毕业于Cornell计算机系
- 1990: 开始编程之路

### 创业期 (1995-2005)
- 1995: 创办Viaweb (电商软件)
- 1998: 拒绝Yahoo收购
- 2002: Viaweb卖给Yahoo
- 2004: 开始写 essays

### YC时期 (2005-2024)
- 2005: 创办Y Combinator，$12k/批
- 2007: 扩大到20+公司
- 2009: 正式基金会化
- 2014: Sam Altman继任CEO
- 2019: 从YC淡出

### 2024至今
- 2024: 发布"Founder Mode"文章引发巨大讨论
- 2024: 大量公开发言AI创业机会
- 持续写 essays

- 集中写How to Start a Startup系列

### 2009-2014: 投资方法论
