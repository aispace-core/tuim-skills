# 04-external-views.md - 他者观察与批评

## 批评与争议

### Y Combinator 相关
1. **权力过大批评** - YC对创投界影响力过大，可能扭曲生态
2. **孵化器模式质疑** - 批量化是否真的能批量产出好公司
3. **PG个人偏好** - 他的投资偏好（技术背景、白人男性）被质疑缺乏多样性
4. **创始人模式争议** - 2024年Founder Mode文章引发很多讨论

### 观点批评
1. **过于简化** - "Good people can fix bad ideas" 被认为过于二元化
2. **幸存者偏差** - 只讲成功案例，不够正视失败
3. **美国中心** - 建议主要针对硅谷/美国创业环境
4. **技术精英主义** - "学编程"建议被认为不现实

### 外部评价

**支持者**:
- 务实、直接、有效
- 简单建议背后有深智慧
- 身体力行自己说的

**批评者**:
- 过于自信有时变傲慢
- 投资成功让他以为什么都能说
- 有时事后归因

## 盲点

1. 不太谈销售/市场能力
2. 不谈如何发现市场需求（默认你知道）
3. 对非技术背景创业者支持少
4. 2024年对AI的态度被认为过于保守
